# SEO und GEO Implementation Plan

**Ziel:** Thematische Zugänge zu vorhandenen Artikeln, redaktionelle Freigaben und belastbare Indexierungssignale.
**Architektur:** Bestehende Supabase-Veröffentlichungen bleiben erhalten. Neue Fassungen landen in einer privaten Entwurfstabelle; Veröffentlichung setzt eine zum Inhalt passende Freigabe im Repository voraus. Gemeinsame URL-, Themen- und Schemafunktionen verbinden serverseitige Module, Hubs, Sitemap und llms.txt.
**Tech Stack:** Next.js 16.3.5, React 19, Supabase, Vitest.

1. Regressionstests für thematische Empfehlungen, Freigaben, Speicherfehler und HTTP-Status schreiben und fehlschlagen sehen.
2. Gemeinsame URL-/Themenlogik; Startseitenmodul, Hubs, gespeicherte interne Links und Autorenprofile ergänzen.
3. Payload validieren; private Entwurfsablage und inhaltsgebundene Freigaben samt ungeführter Migration dokumentieren.
4. Fehler von fehlenden Artikeln unterscheiden, Caches zeitlich begrenzen, 404/503 im Proxy vor Streaming liefern.
5. Crawlerzugang, konsistentes JSON-LD, Sitemap und dynamische llms.txt; IndexNow nach Freigabe ergänzen.
6. Tests, Typprüfung, Lint und Produktionsbuild ohne Produktionszugang; lokale HTTP-Prüfung mit isolierten Testdaten.

Keine Commits, Pushes, PRs, Deploys oder Datenbankoperationen. Keine redaktionelle Löschung bestehender Inhalte.
